# Student Registration System Using Python

## Project Description
This project demonstrates Python file handling through a simple Student Registration System. It stores student information in text files and performs different file operations.

## Operations Performed
- Write student records into a text file.
- Append new student records.
- Read all student records.
- Read individual lines.
- Count total student records.
- Create a backup file named `students_backup.txt`.
- Extract student names and courses into a separate file.

## Technologies Used
- Python
- VS Code

## Files Generated
- `students.txt`
- `students_backup.txt`
- `names_and_courses.txt`

## Objective
To understand Python file handling operations such as reading, writing, appending, copying, and managing text files.
